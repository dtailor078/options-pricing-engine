Key Concepts

What each input and output actually means, for anyone reading the results without a quant finance background.

Spot Price S₀ Input
The current market price of the underlying asset: what it is trading at right now.
Strike Price K Input
The price at which you have the right to buy (call) or sell (put) the asset when the option expires.
Call vs. Put Input
A call profits if the price rises above the strike. A put profits if the price falls below the strike.
Volatility σ Input
How much the asset price fluctuates annually. Higher volatility means a wider range of outcomes and a more expensive option.
Risk-Free Rate Input
The return on a riskless investment, such as a government bond. Used to discount future payoffs to today's value.
Time To Expiry Input
How long until the option expires, in years. More time means more uncertainty and a higher option value.
Monte Carlo Price Output
The option price estimated by averaging discounted payoffs across thousands of simulated price paths.
Black-Scholes Price Output
The analytical closed-form price. Used as a benchmark: the Monte Carlo estimate should converge to this with enough paths.
95% Confidence Interval Output
The range the true price should fall in 95% of the time, computed as the Monte Carlo price plus or minus 1.96 standard errors. It narrows as the path count increases.
Delta Δ Output
How much the option price changes for a one dollar move in the underlying. Ranges from 0 to 1 for calls, and -1 to 0 for puts.
Intrinsic Value Output
The payoff if exercised right now: max(S minus K, 0) for a call. The option price is always at least the intrinsic value.
Geometric Brownian Motion Model
The stochastic process used to simulate price paths: a drift term from the risk-free rate, plus random Gaussian shocks scaled by volatility.
